короткое имя `purpxvpn`). Загружен через @stickers 2026-10-04; иконка пака —

пространством, без обводки — читается и на светлой, и на тёмной теме.

**55 иконок** (батч 1 — базовая навигация, батч 2 — поиск, меню, файлы,
безопасность, статистика, устройства, оплата).

## Как загрузить (десктоп)

1. Чат с [@stickers](https://t.me/stickers) → `/newemoji`
2. Название сета, например `Purpx VPN`
3. Короткая ссылка, например `purpx_nav`
4. Прикрепляйте PNG **файлом** (drag-n-drop как документ) и после каждого
   отправляйте соответствующий эмодзи из таблицы выше
5. `/publish` — готово; ссылка будет вида `t.me/addemoji/purpx_nav`

## Важно про использование именно ботом

- В **inline-кнопках** (Reply/InlineKeyboard) кастомные эмодзи нельзя —
  только обычные юникод. Кастомные — в тексте сообщений, описаниях
  (with `custom_emoji` entities).
- Бот может отправлять `custom_emoji`-энтити только если у него
  **куплен юзернейм на Fragment** (коллекционный). Иначе — отправка от
  личного аккаунта/канала, где сет просто добавлен как эмодзи-пак.
- Кастомные эмодзи полноценно отображаются у Premium-юзеров; остальные
  видят привязанный юникод-эмодзи.
