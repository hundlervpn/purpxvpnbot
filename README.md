# PURPX VPN — Telegram-бот (скелет, данные-заглушки)

Скелет VPN-бота на **aiogram 3.x**. Структура экранов и колбэки повторяют
референс @VPN_TelegramBot (TMG Premium VPN) — снято живой сессией 03.10.2026
(меню, воронка покупки, оплата, карточка подписки, помощь, партнёрка).
eSIM-раздел исключён по требованию. Все данные — заглушки из `bot/stubs.py`.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m bot
```

Токен в `.env` (`BOT_TOKEN=...`), в git не попадает.

## Структура (инлайн-меню на сообщении, как в референсе)

`/start` → «Привет, {имя} 💚 / 💚 Главное меню 💚» + инлайн-кнопки:

```
[ Купить подписку ]                  → экран выбора подписки/ключа
[ Мои подписки (N) ]                 → список подписок
[ Пригласить ][ Помощь ]             → реф. текст | FAQ-меню
[ Всё о PURPX ][ Поддержка ↗ ]       → о сервисе | URL поддержки
[ Партнерская программа ]            → партнёрский текст
```

Панель «Меню» у поля ввода (команды, как в референсе): `/start` Главное меню,
`/help` Помощь, `/buy` Покупка/продление доступа, `/offer` Оферта.
Старая reply-панель снимается при первом `/start` (ReplyKeyboardRemove).
Поддержка: `@purpxsupp`. Пометки «заглушка» из текстов убраны.

Воронка покупки: экран «подписка или ключ для продления» (правит сообщение
меню) → «Создать новую подписку» → инструкция + тарифы (1/3/6/12 мес) →
способ оплаты (СБП / карта / Stars / Crypto) → заглушка-оплата → карточка
подписки (ID, устройства, протокол, срок, ссылка-ключ).

Карточка подписки: Подключить (инструкция) · Мои устройства · Продлить ·
Добавить локацию · Изменить протокол · Поделиться · Назад — все заглушки.

## Файлы

- `bot/main.py` — вход, long polling, `get_me()` для имени бота
- `bot/config.py` — токен из `.env`
- `bot/keyboards.py` — все инлайн-клавиатуры (ряды = референс)
- `bot/stubs.py` — тарифы, подписки, выдача ключа, все тексты
- `bot/handlers.py` — колбэки и экраны (навигация edit'ом/новыми сообщениями как в референсе)

## Тестирование (сессия Telegram-аккаунта)

MCP-сессия: `~/.zcode/mcp-servers/telegram-mcp/` — `purpx.session`,
`.env` с `TELEGRAM_API_ID/HASH` и `TELEGRAM_SESSION_PATH`.
Скрипты: `walk_ref.py`/`walk_deep.py` (обход референса), `walk_purpx.py`
(обход нашего бота), дампы в `/tmp/*_walk*.json`. Логин: `qr_login.py`,
добавка пароля 2FA: `password_login.py`.

Важно: MCP-сервер читает `.env` при старте — после создания сессии нужно
переподключение сервера (в интерфейсе: /mcp → reconnect), иначе
`telegram_status` продолжит отвечать «no session».

## Отличия от референса (осознанные)

- Цены/брендинг — PURPX (не TMG), eSIM-строка и кнопка отсутствуют.
- Зелёные кнопки референса — это MTProto `KeyboardButtonStyle` (bg_success),
  через Bot API/aiogram не задаётся; для полного совпадения нужен Telethon-бот.
- «Связаться с поддержкой» — прямая URL-кнопка (у референса — колбэк-менеджер).

## Безопасность

- Токен бота светился в переписке — перед продом перевыпустить (@BotFather /revoke).
- `api_id`/`api_hash` и сессия аккаунта — секреты, в git не коммитить.
- Пароль 2FA в чат больше не отправлять.
